Pertanyaan Umum (FAQ)

Segala hal yang perlu Anda ketahui sebelum memesan.

Berapa lama pengerjaannya?

Pengerjaan reguler membutuhkan waktu 2-3 hari kerja. Jika deadline mendesak, pilih layanan Express 24 jam fast-track.

Apa saja output file yang akan saya dapatkan?

Untuk peta: file siap cetak High-Res (PDF & PNG 300 DPI) serta data spasial (.SHP, GeoJSON, KMZ). Untuk arsitektur: DWG, PDF, dan Excel (RAB). Untuk website: source code siap deploy ke GitHub Pages.

Bagaimana jika hasilnya perlu direvisi?

Kami memberikan 2x garansi revisi minor (warna, judul layout, legenda, koreksi typo) secara GRATIS.
